# pure algorithm — 已还原的纯算法部分

本目录记录**不依赖宿主环境**即可复现的部分;仍依赖宿主环境的部分见

## 1. token 外层容器(已还原,可纯 Python 复现)

- 形态:`'7' + base64(raw)`
- `raw` = 3 字节头 + UTF-8 载荷;同一版本下头部固定(`7baf20`)
- 长度带:441 / 445 / 449 / 453,满足 `(len(token) - 1) % 4 == 0`;应用(真机/iv8)产出的原始长度为 445,
  差值来自调用内部的随机数,不是版本差异

## 2. 时间戳换算(已还原)

```python
ts = int(sts) + (480 + tz_offset_minutes) * 60000   # sts = 响应下发 __zp_sts__;UTC+8 时 tz_offset_minutes = 0
```

## 3. 种子消费契约(协议侧算法,已还原)

受保护接口响应 `set-cookie` 下发三元组 `__zp_sseed__`(随机种子)/ `__zp_sname__`(安全 JS 版本名)/
`__zp_sts__`(服务端毫秒时间戳),客户端须:

1. 按 `__zp_sname__` 加载对应版本的安全 JS(隐藏 iframe 内);
2. 调 `new ABC().z(seed, ts)` 生成 token,写入 `.zhipin.com` 域的 `__zp_stoken__`;
3. 清除上述三个一次性 cookie;
4. 把新 token 持久化回会话 —— 否则下一次请求被判陈旧。

## 4. 尚未纯算法化的部分(边界要写清楚)

- 载荷(body)由安全 JS 内的**自研字节码 VM**在运行时组装,并读取宿主环境表面
  (canvas 指纹、WebGL 参数、screen/window 尺寸、navigator、history 等);
- 在薄 DOM 存根下产物会系统性偏短(约 8%)并被拒 —— 说明体积差来自宿主能力而非算法分支;
- 因此本案例目前**没有**纯 Python 端口:可行的等价路径是环境仿真(见 `../environment emulation/`)。
- 若未来做纯 Python 端口,应放在本目录,并附:同一非随机输入下的逐字节对照样例、长度带断言、
  VM 字节码解释器实现与可重放的固定向量。

## 5. 风控观察(复现者需要注意)

- 受保护端点的拒绝码会升级:先"环境异常",反复用被拒产物探测后会升到账户级"异常行为" —— 请控制探测次数;
- 低风险端点(如条件查询类)不校验 token,拿它当验收会得出错误结论:判定端点是否真的校验,
  方式是删掉 token 后看返回是否变化;
- 判别门是否在"产物侧"还是"传输侧":用真机产出的 token 从纯 Python 客户端回放一次即可。
