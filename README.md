# reserver — Web 协议逆向案例集

按目标站点分目录存放的可复现案例。每个案例都给出**浏览器外**的运行链路,以及"哪一步还需要宿主环境"的明确边界。

## 案例索引

| 目录 | 目标 | 交付形态 | 状态 |
| --- | --- | --- | --- |
| [`tds/`](tds/) | 腾讯行为式验证码(`tdc.js` Chaos VM 的 `collect`/`eks` 参数 + 滑块缺口) | **纯 Python**(字节码解码 → 常量提取 → 明文模板 → XTEA 变体加密),Node 仅首次提参用 | 跨 2023 个线上版本逐字节一致,端到端拿到 ticket |
| [`boos/`](boos/) | BOSS直聘会话风控 token `__zp_stoken__` | **环境仿真**(Python 协议层 + `iv8` 嵌入式 JS 引擎提供宿主环境表面) | 活体验收通过;纯 Python 端口未落地(见 `boos/pure algorithm/`) |

## 两种交付形态的区别(为什么不是每个案例都能纯 Python)

- **纯算法**:决定性变换全部在本地重建,不依赖运行时环境 —— `tds/` 属于这一类。
- **环境仿真**:签名/校验读取宿主环境表面(canvas、WebGL、navigator、窗口尺寸…),在薄存根下产物会系统性偏短
  并被拒,因此需要一个保真的本地宿主 —— `boos/` 属于这一类。
  这类案例的诚实标签是 `snapshot-driven`:随机种子每次现取,但环境画像来自真实浏览器采集。

## 通用约定

- 只读采集,请求节流 ≥1s;不做写/提交类请求。
- 会话态与敏感文件不入库:`cookies.json` 等一律由使用者本地生成(结构见各案例的 `cookies.example.json`),
  原始报文样例均已脱敏(见 `.gitignore`)。
- 被保护端点的拒绝码可能升级(先环境级、后账户级):不要用**被拒的产物**反复探测,验证优先走
  "删掉产物看返回是否变化"和"真机产物回放"这两种低成本判别。
